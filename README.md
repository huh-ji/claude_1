# FloatMemo

다른 프로그램(Microsoft Teams, 브라우저 등) **위에 항상 떠 있는** 데스크탑 메모장입니다.
Electron 으로 만들어져 Windows / macOS / Linux 에서 동작합니다.

## 기능

| 기능 | 사용 방법 |
| --- | --- |
| 여러 메모 | 제목줄의 **+** 버튼 또는 `Ctrl+N` 으로 새 메모. 메모마다 내용·위치·크기·색·글자 크기·투명도·고정·접기 상태가 따로 저장됨. 새 메모는 만든 메모의 색·글자 설정을 따라감 |
| 메모 닫기 (✕) | 메모 창만 닫고 내용은 보존. 빈 메모는 닫을 때 자동 정리 |
| ⋯ 더보기 | 새 메모 / **메모 목록**(● 열림, ○ 닫힘, 클릭하면 열림) / **빠른 색상** / **단축키 도움말** / **앱 종료** (모든 메모를 한 번에 닫고, 다음 실행 때 열려 있던 메모가 모두 다시 열림) |
| 트레이 아이콘 | 작업 표시줄 오른쪽 알림 영역의 FloatMemo 아이콘. 클릭하면 열린 메모를 앞으로, 우클릭하면 ⋯ 메뉴와 같은 항목 |
| 메모 삭제 | ⚙ 설정 패널의 **이 메모 삭제** (내용이 있으면 확인 창) |
| 항상 위에 표시 | 메모마다 기본 켜짐. 📌 버튼으로 끄고 켤 수 있음 |
| 내용 접기 | 📌 왼쪽의 ⌃ 버튼. 제목줄만 남기고 창을 줄여 뒤쪽 화면을 클릭할 수 있음. 맨 위 고정은 그대로 유지되고, 다시 누르면 원래 크기로 펼쳐짐 (접힌 상태도 저장됨) |
| 위치 이동 / 크기 조절 | 상단 바를 드래그해서 이동, 창 가장자리를 끌어 크기 조절 (위치·크기는 자동 저장) |
| 배경 투명도 | ⚙ 설정 패널의 슬라이더 (0% = 완전 투명 ~ 100%) 또는 `Ctrl+Shift+↑ / ↓`. 글자는 항상 선명하게 유지되고 메모지 배경만 투명해짐 |
| 글자 크기 | ⚙ 설정 패널의 슬라이더 (8 ~ 48px) 또는 `Ctrl + / Ctrl −` (`Ctrl 0` 으로 기본값) |
| 글씨 굵게 | **B** 버튼 또는 `Ctrl+B` |
| 글자색 / 배경색 | 글자를 선택하고 상단 바의 **A** 버튼 → 팔레트에서 색 클릭 (같은 색을 다시 눌러도 적용). **+** 로 직접 고른 색은 팔레트에 남음. **서식 지우기** 또는 `Ctrl+\` |
| 빠른 색상 | 글자를 선택하고 `Ctrl+1` ~ `Ctrl+9`. 기본값은 1 빨간 글자, 2 파란 글자, 3 노란 배경, 4 초록 글자, 5 분홍 배경. ⋯ → 빠른 색상 → **빠른 색상 편집…** 에서 색상 코드·종류·순서·이름을 바꾸고 추가/삭제 (최대 9개, 모든 메모에 바로 적용) |
| 붙여넣기 | 다른 곳(Notion, 웹, Word, Google Docs 등)에서 복사한 굵게·기울임·밑줄·취소선·글자색·배경색·줄바꿈·목록·토글을 살려서 붙여넣음. 글꼴·글자 크기는 메모 설정을 따름. 서식 없이는 `Ctrl+Shift+V` |
| 기본 글자색 / 메모지 색 | ⚙ 설정 패널에서 메모 전체의 기본 글자색과 메모지(배경) 색 변경, 초기화 버튼 제공 |
| 토글 블록 (노션 스타일) | 줄 맨 앞에서 `>` 다음 `Space` 또는 `Tab` (뒤에 있던 글은 토글 제목이 됨), ▸ 버튼, 또는 `Ctrl+Shift+T`. 화살표를 클릭하면 접기/펼치기 |
| 자동 저장 | 입력할 때마다 내용·접힘 상태·투명도·창 위치를 자동 저장, 다음 실행 시 복원 |
| 빠른 호출 | `Ctrl+Shift+M` (macOS: `Cmd+Shift+M`) 으로 어디서든 열린 메모 모두 보이기/숨기기 |

### 토글 블록 조작

- 토글 바로 아래 줄에서 `Tab` → 그 줄을 토글 안(맨 끝)으로 넣기. 토글 제목에서 누르면 토글째로 위 토글 안에 넣기
- 토글 안의 줄에서 `Shift+Tab` → 토글 밖(바로 아래)으로 꺼내기
- 제목 줄에서 `Enter` → 토글 본문으로 이동
- 본문의 빈 마지막 줄에서 `Enter` → 토글 밖으로 나가기
- 비어 있는 토글 제목에서 `Backspace` → 일반 줄로 되돌리기
- 본문 첫 줄 맨 앞에서 `Backspace` → 제목 끝으로 이동

## Windows 에서 바로 쓰기 (exe 내려받기)

GitHub Actions 가 Windows 용 실행 파일을 빌드해 **Releases** 페이지에 올립니다.
<https://github.com/huh-ji/claude_1/releases/latest>

- `FloatMemo-<버전>-Portable.exe` : 설치 없이 다운로드 폴더에서 바로 더블클릭하면 실행됩니다.
- `FloatMemo-<버전>-Setup.exe` : 설치 버전 (바탕화면 바로가기 생성).

코드 서명이 되어 있지 않아 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다.
**추가 정보 → 실행** 을 누르면 됩니다.

새 빌드가 필요하면 GitHub 의 **Actions → Build Windows exe → Run workflow** 를 누르거나, `v*` 태그를 푸시하면 됩니다.

## 소스로 실행

```bash
npm install
npm start
```

## 설치 파일 만들기 (선택)

```bash
npm run dist
```

`dist/` 폴더에 Windows 는 설치 파일(NSIS)과 포터블 실행 파일, macOS 는 DMG, Linux 는 AppImage 가 생성됩니다.
Windows 설치 파일은 Windows 에서, macOS DMG 는 macOS 에서 빌드하는 것이 가장 안정적입니다.

## 테스트

```bash
npm test
```

Chromium(Playwright) 에서 에디터의 굵게 / 색상 팔레트·빠른 색상 / 토글 생성·Tab 들여넣기·접기·탈출 / 붙여넣기 서식 유지 / 저장 동작을 검증합니다.
Playwright 가 없다면 `npm install -D playwright` 후 `npx playwright install chromium` 이 필요합니다.

## 알려진 제한

- 배경 투명도는 창 자체를 투명하게 만드는 방식이라 **Linux** 에서는 컴포지터 설정에 따라 투명이 적용되지 않을 수 있습니다. Windows / macOS 는 정상 동작합니다.
- 배경을 0% 로 하면 상단 바만 희미하게(최소 35%) 남습니다. 이동과 크기 조절을 할 수 있도록 일부러 남겨둔 것입니다.
- 다른 프로그램이 **전체 화면(배타적 풀스크린)** 모드일 때는 운영체제 정책상 그 위에 뜨지 않을 수 있습니다. 일반 창·최대화 창 위에는 표시됩니다.
- 앱 종료는 트레이 메뉴의 **종료** 로 합니다. ✕ 는 메모 하나만 닫습니다. 트레이 아이콘이 안 보이면 알림 영역의 `^` (숨겨진 아이콘) 안에 있을 수 있습니다.
- 1.2 이하 버전의 메모는 처음 실행할 때 자동으로 새 형식(메모 목록)으로 옮겨집니다.
- 붙여넣기 서식 유지는 표준 HTML(`<details>` 토글, 목록, 굵게, 색 등)과 Notion 색 이름을 기준으로 만들었습니다. Notion 이 클립보드에 넣는 토글 형식은 공식 자료로 확인하지 못해서, Notion 토글이 토글 대신 글머리표 목록으로 붙을 수 있습니다.
- 저장 위치: 운영체제의 앱 데이터 폴더 (`%APPDATA%\float-memo\state.json`, `~/Library/Application Support/float-memo/state.json`, `~/.config/float-memo/state.json`)

## 구조

```
build/
  icon.png, icon.ico   앱 아이콘
.github/workflows/
  build-windows.yml    Windows exe 빌드 + Release 업로드
src/
  main.js      Electron 메인 프로세스 (투명 창, 항상 위, 설정·상태 저장, 크기 조절)
  preload.js   렌더러 ↔ 메인 안전한 브리지 (contextBridge)
  index.html   UI 마크업
  style.css    스타일 (포스트잇 느낌, 토글 블록)
  renderer.js  에디터 로직 (굵게, 토글 블록, 색상 팔레트·빠른 색상, 설정 패널, 자동 저장)

  options.*    빠른 색상 편집 / 단축키 도움말 창
test/
  renderer.test.js  Playwright 기반 에디터 테스트
```
